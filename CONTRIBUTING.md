# Contributing

## Code contributions

License is `AGPL-3.0-or-later` (see [`LICENSE`](LICENSE) and the
[README](README.md#status-and-license)) — outside pull requests are welcome. The flow is
lightweight:

1. Fork the repo and create a branch.
2. Open a pull request against `main`.
3. CI must pass — `main` is branch-protected and requires both `test (ubuntu-latest)` and
   `test (macos-latest)` to be green before merge.
4. A maintainer reviews and merges.

No CLA, no RFC process. **Issue reports are welcome too** — see below.

## AI-assisted contributions

AI-assisted work is welcome here — it's already how a lot of this project gets built. Every
commit in this repo's history that came out of an agent session says so explicitly, with a
`Co-Authored-By:` trailer and a session link. The two rules below just extend that same
disclosure convention to issues and pull requests, and add one guardrail for bug reports
specifically.

### Disclosure is required, not optional

If a pull request or issue was substantially drafted or generated by an AI agent, say so in
the PR description or issue body. A short line is enough — the point is that a reviewer
shouldn't have to guess.

### The human submitter is fully accountable

AI authorship doesn't lower the review bar or shift responsibility elsewhere. Opening a PR or
filing an issue asserts that you — the human submitting it — have personally reviewed and
verified its content, exactly as if you'd written it by hand. "The agent said so" is not a
substitute for having checked.

### No unreviewed AI-generated bug reports

AI-*assisted* investigation into a bug is welcome. What's not welcome is relaying an LLM's
unverified guess as if it were a confirmed repro — that wastes maintainer time chasing
something that was never actually reproduced.

Before filing a bug report, the human submitting it must have personally verified the
described behavior is real: either reproduced it themselves, or watched the AI reproduce it
and confirmed the evidence. The [bug report form](.github/ISSUE_TEMPLATE/bug_report.yml) has a
required checkbox for this — it won't let you submit without it.
