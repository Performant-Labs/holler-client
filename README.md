# holler-client

Thin client for the Holler talk circuit. Joins holler-server with a minted token and drives local coding-agent bodies (v1: OpenCode). This machine does **not** run Herdr.

See [issue #1](https://github.com/Performant-Labs/holler-client/issues/1) (orientation) and [docs/adr](docs/adr/README.md).

Companion: [holler-server](https://github.com/Performant-Labs/holler-server).
